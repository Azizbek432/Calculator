## 🇬🇧 About the Project
This is a functional **Web Calculator** built using pure HTML, CSS, and JavaScript. Inspired by **Bro Code's** tutorials, it focuses on implementing math logic within a browser environment and styling a grid-based user interface.

### ✨ Key Features:
* **Math Operations:** Handles addition, subtraction, multiplication, and division.
* **Dynamic Interaction:** Responds to button clicks and updates the display in real-time.
* **User-Friendly Layout:** Built with CSS Grid/Flexbox for a consistent button arrangement.
* **Error Handling:** Designed to process calculations accurately.
